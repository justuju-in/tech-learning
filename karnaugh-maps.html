The Problem: Algebra se Simplify Karna

Ye expression simplify karo:

F = A'B'C + A'BC + AB'C + ABC

Boolean Algebra steps:

  1. F = A'C(B' + B) + AC(B' + B)
  2. F = A'C(1) + AC(1)   [Complement law: B' + B = 1]
  3. F = A'C + AC
  4. F = C(A' + A)
  5. F = C(1) = C
5 steps! Aur agar galat law lagaya toh? Galat answer!

K-Map Kya Hai?

Ek K-map basically ek special truth table hai jo grid (table) ki form mein draw hoti hai.

Har cell ek minterm represent karti hai — jaise truth table ki ek row.

Lekin ek special rule hai:

Adjacent (bagal wali) cells mein sirf EK variable change hota hai!

Isko kehte hain Gray Code ordering.

Ye kyu important hai? Kyunki agar do adjacent cells mein 1 hai, toh wo variable jo change ho rahi hai — usse eliminate kar sakte hain!

Grouping Rules (Bahut Important!)

1. Size = Power of 2

Groups ka size sirf 1, 2, ya 4 ho sakta hai (2-var K-map mein)

2. Rectangular Shape

Groups hamesha rectangle ya square hone chahiye — diagonal nahi!

3. Overlap Allowed

Ek cell do groups mein ho sakti hai — koi problem nahi!

4. Bigger = Better

Jitna bada group, utna simple expression. Hamesha sabse bade group banao!

5. Cover ALL 1s

Har ek 1 kisi na kisi group mein hona chahiye!

6. Fewest Groups

Kam se kam groups use karo — unnecessary groups mat banao!

3-Variable K-Map: Layout

3 variables: A, B, C

Grid size: 2 rows x 4 columns = 8 cells

Column order Gray Code mein hai: 00, 01, 11, 10
(NOT 00, 01, 10, 11!) — Ye sabse important rule hai!
A \ BC 00 01 11 10
A=0 m0
A'B'C'		 m1
A'B'C		 m3
A'BC		 m2
A'BC'
A=1 m4
AB'C'		 m5
AB'C		 m7
ABC		 m6
ABC'

Notice: m2 aur m3 ka order swap hai! Gray code ki wajah se.

Gray Code Kyu?

Normal binary order: 00, 01, 10, 11

01 se 10 mein dono bits change hue — ye adjacent nahi hai!

Gray Code order: 00, 01, 11, 10

Har step mein sirf EK bit change hoti hai:

  • 00 → 01 (C changes)
  • 01 → 11 (B changes)
  • 11 → 10 (C changes)
Iska matlab: K-map mein jo cells bagal mein hain, unke minterms mein sirf ek variable ka difference hai. Tabhi grouping kaam karti hai!
Aur ek secret: First column (00) aur last column (10) bhi adjacent hain! Unme bhi sirf ek bit ka difference hai. Map "wrap around" karta hai!

Example 1: F(A,B,C) = Σm(0,2,4,6)

Step 1: Kaunse minterms? m0, m2, m4, m6 — ye sab even numbers hain!

Step 2: K-map bharo

A \ BC 00 01 11 10
A=0 1 0 0 1
A=1 1 0 0 1

Step 3: Groups banao — first aur last columns wrap around karke adjacent hain!

A \ BC 00 01 11 10
A=0 1 0 0 1
A=1 1 0 0 1
Group of 4: A changes, B changes, C = 0 constant → F = C'

A=1 0 1 1 0

Middle 2 columns mein saari 1s hain — group of 4!

A=0 0 1 1 0
A=1 0 1 1 0

Example 3: F(A,B,C) = Σm(0,1,2,3,5)

Wrap-Around Groups Samjho

K-map mein first column aur last column adjacent hain!
Socho ki map ek cylinder hai — left aur right edge connected hain.

Toh ye wrap-around group valid hai: F = C'

4-Variable K-Map: Layout

4 variables: A, B, C, D

Grid size: 4 x 4 = 16 cells

Ab rows BHI Gray code mein hain! Rows: 00, 01, 11, 10. Columns: 00, 01, 11, 10.
AB \ CD 00 01 11 10
00 m0 m1 m3 m2
01 m4 m5 m7 m6
11 m12 m13 m15 m14
10 m8 m9 m11 m10

Row order: 00, 01, 11, 10 (Gray code!) — Row 10 is LAST, not third!

4-Var K-Map: Wrapping Rules

4-variable K-map mein map dono directions mein wrap around karta hai!

Left-Right Wrap

First column (CD=00) aur last column (CD=10) adjacent hain

Jaise 3-var map mein tha

Top-Bottom Wrap

First row (AB=00) aur last row (AB=10) adjacent hain!

Ye naya hai — 4-var mein rows bhi wrap karti hain

Corner trick: Charon corners (m0, m2, m8, m10) ek group bana sakte hain!
Kyunki ye sab wrap-around se adjacent hain.

Valid group sizes: 1, 2, 4, 8, 16

Example 1: F(A,B,C,D) = Σm(0,2,5,7,8,10,13,15)

Step 1: K-map bharo

AB \ CD 00 01 11 10
00 1 0 0 1
01 0 1 1 0
11 0 1 1 0
10 1 0 0 1

Example 1 (continued): Grouping

Step 2: Groups banao

AB \ CD 00 01 11 10
00 1 0 0 1
01 0 1 1 0
11 0 1 1 0
10 1 0 0 1

Blue group (4 corners, wrap-around): m0, m2, m8, m10

A changes, B=0 constant? Nahi — B bhi change. C=0? Nahi. D=0 constant! Actually: B'D' — B=0, D=0

In cells mein: B=0, D=0 → B'D'

Green group (middle 4): m5, m7, m13, m15

In cells mein: B=1, D=1 → BD

F = B'D' + BD   (ye XNOR of B and D hai!)

Example 2: F(A,B,C,D) = Σm(0,1,2,3,4,5,6,7)

Ye m0 se m7 tak sab hain — pehle 8 minterms!

00 1 1 1 1
01 1 1 1 1
11 0 0 0 0
10 0 0 0 0

Top 2 rows = A=0 wali rows (AB=00 aur AB=01). In dono mein A=0.

Group of 8: B changes, C changes, D changes — sirf A=0 constant hai.

F = A'   Simple!

Example 3: Overlapping Groups

F = C' + D'   (overlap on column 00 is fine!)

Don't Care Conditions

Kabhi kabhi kuch input combinations kabhi hote hi nahi.

Example: BCD mein digits 0-9 represent hote hain (4 bits). Lekin 1010 (10) se 1111 (15) — ye invalid hain!

In invalid combinations ko hum "Don't Care" bolte hain aur K-map mein X likhte hain.

X ka matlab: Isko 0 bhi maan sakte ho, 1 bhi — jo bhi bigger group banane mein help kare!

Don't cares ko 1 maanna optional hai — sirf tab maano jab group bada ho raha ho. Zaroori nahi ki sab X ko 1 maano!

Don't Care Example

F(A,B,C,D) = Σm(1,3,7,11,15) + d(0,2,5)

d() = don't care minterms

AB \ CD 00 01 11 10
00 X 1 1 X
01 0 X 1 0
11 0 0 1 0
10 0 0 1 0

Agar X ko 1 maane (m0, m2, m5):

AB \ CD 00 01 11 10
00 X 1 1 X
01 0 X 1 0
11 0 0 1 0
10 0 0 1 0
Blue: m0,m1,m2,m5 (using X!) → A'C' ... wait let's re-check. Actually: Green: entire CD=11 column → CD. Blue: top rows using Xs → A'. So F = CD + A'... but we must verify. Key point: Don't cares help make bigger groups!

Don't Care: Clean Example

F(A,B,C) = Σm(1,5,7) + d(2,6)

A \ BC 00 01 11 10
A=0 0 1 0 X
A=1 0 1 1 X

Without don't cares: m1, m5 = group of 2 (B'C), m5, m7 = group of 2 (AC) → F = B'C + AC

With don't cares as 1:

A \ BC 00 01 11 10
A=0 0 1 0 X
A=1 0 1 1 X

Blue: m1, m2, m5, m6 (wrap!) → C'... Hmm, let me redo.

m1+m5 group → B'C. m5+m7+m6(X) = group → AC or A. Don't cares expand groups! The key lesson: X lets you make bigger groups = simpler answers!

K-Maps aur Real Code

Socho tumhare paas ye complex condition hai:

if ((a && !b && c) || (!a && !b && c) || (a && b && c) || (!a && b && c)) {
    doSomething();
}

Step 1: Variables identify karo: A, B, C

Step 2: Minterms: AB'C + A'B'C + ABC + A'BC = Σm(1,3,5,7)

Step 3: K-map se simplify:

A \ BC 00 01 11 10
A=0 0 1 1 0
A=1 0 1 1 0
F = C → Simplified code: 
if (c) {
    doSomething();
}

Flowchart Decision Simplification

Imagine a flowchart mein ye decision hai:

"Show discount if: (premium member AND has coupon) OR (premium member AND no coupon AND order > 500) OR (not premium AND has coupon AND order > 500)"

Variables: P (premium), C (coupon), O (order>500)

F = PC + PCO' ... wait: PC + P C' O + P'CO = Σm(6,7,4,3) nahi...

Let me map: P=A, C=B, O=C

  • AB (premium + coupon): m6, m7
  • AB'C (premium, no coupon, big order): m5
  • A'BC (not premium, coupon, big order): m3

F = Σm(3,5,6,7)

P \ CO 00 01 11 10
P=0 0 0 1 0
P=1 0 1 1 1
Blue: PC   Green+Orange: m3+m7 = CO, m5 is separate = PC'O? Actually: F = PC + CO. Simpler decision!

K-Map Thinking in Code

Ab jab bhi koi complex condition dikhti hai — K-map banao, simplify karo!

Before K-Map

if ((x && y && !z) ||
    (x && !y && !z) ||
    (!x && y && !z) ||
    (!x && !y && !z)) {
  // ...
}

After K-Map

if (!z) {
  // ...
}

All 4 terms had z=0!

Pro tip: Real code mein 2-3 conditions se zyada ho toh truth table banao, K-map draw karo, aur simplified condition likho. Code readable bhi hoga aur efficient bhi!
