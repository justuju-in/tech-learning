Tumne ek circuit banaya. 5-6 gates lage hain. It works!

Lekin sochke dekho:

  • Har gate ka paisa lagta hai chip mein
  • Zyada gates = zyada bijli (power)
  • Zyada gates = zyada slow circuit
  • Zyada gates = zyada garmi (heat)
Kya hum kam gates mein wahi kaam kar sakte hain? Bilkul! Lekin kaise?

Dekho Ye Expression

F = A'BC + AB'C + ABC' + ABC

Isme kitne gates lagenge?

  • 4 AND gates (har term ke liye)
  • 3 NOT gates (A', B', C' ke liye)
  • 3 OR gates (4 terms ko combine karne ke liye)
  • Total: 10 gates!
Kya ye expression simplify ho sakta hai? Haan! Lekin HOW?

Code Mein Bhi Yahi Problem Hai

Ye padho aur batao kya ho raha hai:

if ((a && b) || (a && c) || (a && !b && c)) {
    doSomething();
}

Samajh aaya? Mushkil hai na padhna?

Ab ye dekho:

if (a && (b || c)) {

Dono ka result SAME hai! Lekin doosra wala kitna simple hai!

Boolean Algebra Kya Hai?

Ek set of RULES jo logic expressions ko simplify karte hain

Jaise math mein rules hain:

  • a + 0 = a
  • a * 1 = a
  • a * (b + c) = ab + ac

Waise hi Boolean Algebra mein rules hain AND, OR, NOT ke liye!

Yaad rakho: OR is like addition (+), AND is like multiplication (.), NOT is the bar on top (A')

Basic Laws

The Rules of the Game

In rules ko yaad karo — ye tumhare tools hain simplification ke liye

1. Identity Law

"Koi cheez aur zero ko OR karo — woh cheez hi rahegi"

OR Identity

A + 0 = A

Zero ke saath OR karna = kuch nahi karna

A0A + 0
000
101

AND Identity

A · 1 = A

Ek ke saath AND karna = kuch nahi karna

A1A · 1
010
111
Real life: "Main jaaungi YA koi nahi jaayega" = "Main jaaungi." Zero ka matlab = koi nahi.

2. Null / Domination Law

"Ek bada player aata hai toh baaki sab cancel"

OR Domination

A + 1 = 1

1 ke saath OR = hamesha 1 (TRUE wins!)

A1A + 1
011
111

AND Domination

A · 0 = 0

0 ke saath AND = hamesha 0 (FALSE wins!)

A0A · 0
000
100
Real life: "Sab log jaayenge AUR koi nahi jaayega" = "Koi nahi jaayega." Zero sabko dominate karta hai AND mein!

3. Idempotent Law

"Ek cheez ko do baar karo — wahi rahega"

OR version

A + A = A

Apne aap ko OR karo = wahi result

AAA + A
000
111

AND version

A · A = A

Apne aap ko AND karo = wahi result

AAA · A
000
111
Real life: "Main jaaungi YA main jaaungi" — bhai, ek baar bol do bas! Result same hai.

4. Complement Law

"Koi cheez OR uska opposite = hamesha TRUE"

OR Complement

A + A' = 1

Kuch YA uska ulta = guaranteed TRUE

AA'A + A'
011
101

AND Complement

A · A' = 0

Kuch AUR uska ulta = guaranteed FALSE

AA'A · A'
010
100
Real life: "Baarish hogi YA nahi hogi" — ye toh 100% TRUE hai! Aur "Baarish hogi AUR nahi hogi" — ye toh impossible hai = FALSE.

5. Double Negation

"NOT ka NOT = original wapas"

(A')' = A
AA'(A')'
010
101
Real life: "Ye sach nahi hai ki main nahi jaaungi" = "Main jaaungi!"
Double negative = positive. Hindi mein bhi, English mein bhi, aur Boolean mein bhi!
Code mein: !!true === true   aur   !!false === false

6. Commutative & Associative Laws

Commutative (Order doesn't matter)

A + B = B + A
A · B = B · A

Jaise 3 + 5 = 5 + 3, waise hi OR aur AND mein order se farak nahi padta

Associative (Grouping doesn't matter)

(A + B) + C = A + (B + C)
(A · B) · C = A · (B · C)

Brackets kahin bhi lagao, result same — jaise (2+3)+4 = 2+(3+4)

Ye dono rules math se bilkul same hain — kuch naya nahi! Tum pehle se jaanti ho ye.

7. Distributive Law

"Ye sabse POWERFUL rule hai simplification ke liye!"

A · (B + C) = A·B + A·C

Ye toh math wala hi hai: a(b + c) = ab + ac

A + B·C = (A + B) · (A + C)
Ye wala math mein NAHI hota! Ye Boolean special hai. Yaad rakho!

De Morgan's Theorems

Ye BOHOT important hai!

Gates, code, circuits — har jagah kaam aata hai

De Morgan's Theorem 1

(A + B)' = A' · B'

"NOT of OR = AND of NOTs"

Truth table se prove karte hain:

ABA+B(A+B)'A'B'A'·B'
0001111
0110100
1010010
1110000
Column 4 aur Column 7 exactly same hain! Proved!

De Morgan's Theorem 2

(A · B)' = A' + B'

"NOT of AND = OR of NOTs"

Truth table se prove karte hain:

ABA·B(A·B)'A'B'A'+B'
0001111
0101101
1001011
1110000
Yahan bhi Column 4 aur Column 7 same hain! Proved!

De Morgan's — Gates Se Connect Karo

Yaad hai universal gates?

NOR Gate = NOT(OR)

NOR(A,B) = (A + B)'

De Morgan's se:

= A' · B'

NOR = dono ka NOT, phir AND!

NAND Gate = NOT(AND)

NAND(A,B) = (A · B)'

De Morgan's se:

= A' + B'

NAND = dono ka NOT, phir OR!

Ye toh tum pehle se jaanti ho! NAND aur NOR universal gates hain — De Morgan's batata hai kyun ye itne powerful hain.

De Morgan's — Code Mein

JavaScript/React mein ye BOHOT kaam aata hai:

Theorem 1: NOT of OR = AND of NOTs

// Ye dono same hain:
!(a || b)    ===    (!a && !b)

Theorem 2: NOT of AND = OR of NOTs

// Ye dono same hain:
!(a && b)    ===    (!a || !b)
Example: "User logged in NAHI hai AUR admin NAHI hai"
!loggedIn && !isAdmin is same as !(loggedIn || isAdmin)
Jab bhi code mein !(... || ...) ya !(... && ...) dikhe, De Morgan's use karo to simplify!

Simplification

Ab Rules Use Karte Hain!

Step by step, ek ek law lagaake expressions chhote karo

Example 1 (Easy)

Simplify karo:

AB + AB' = ?
Step 1: AB + AB'
Step 2: A(B + B')    [Distributive law — A ko bahar nikalo]
Step 3: A · 1    [Complement law — B + B' = 1]
Step 4: A    [Identity law — A · 1 = A]
AB + AB' = A
Matlab: Agar A TRUE hai, toh B kuch bhi ho — result TRUE hi hoga. B matter hi nahi karta!

Example 2 (Medium)

Simplify karo:

A'B + AB + AB' = ?
Step 1: A'B + AB + AB'
Step 2: (A' + A)B + AB'    [First 2 terms se B ko bahar nikalo — Distributive]
Step 3: 1 · B + AB'    [Complement — A' + A = 1]
Step 4: B + AB'    [Identity — 1 · B = B]
Step 5: (B + A)(B + B')    [Distributive — B + AC = (B+A)(B+C) form]
Step 6: (B + A) · 1    [Complement — B + B' = 1]
Answer: A + B    [Identity + Commutative]

Example 3 (Harder) — Wahi Motivation Wala!

Yaad hai ye?

F = A'BC + AB'C + ABC' + ABC
Step 1: A'BC + AB'C + ABC' + ABC
Step 2: A'BC + AB'C + AB(C' + C)    [Last 2 terms se AB bahar nikalo]
Step 3: A'BC + AB'C + AB    [Complement — C' + C = 1, Identity — AB·1 = AB]
Step 4: (A' + A)BC + AB    [Nahi... wait, ye nahi chalega. Sochte hain...]

Galat approach? Koi nahi! Doosra raasta try karte hain...

Example 3 (continued)

Step 3 se wapas shuru:

Step 3: A'BC + AB'C + AB

Trick: AB term ko DUPLICATE karo (A + A = A, toh ek extra copy add karna allowed hai!)

Step 4: A'BC + AB'C + AB + AB    [Idempotent — AB + AB = AB, toh extra copy allowed]
Step 5: (A' + A)BC + A(B'C + B)    [Group differently + Distributive]
Step 6: BC + A(B + C)    [Complement + simplify B'C + B = B + C]
Answer: AB + AC + BC
10 gates se ghataake 5 gates! Almost aadhe! Yahi hai Boolean Algebra ki power.

Simplification Tips

Strategy yaad rakho:
  1. Common terms dhundho — Distributive law se bahar nikalo
  2. Complement pairs dhundho — A + A' = 1 dikhta hai toh use karo
  3. Term duplicate karo agar zaroorat ho — A + A = A, toh extra copy FREE hai
  4. De Morgan's use karo — NOT wale expressions ke liye
  5. Identity / Null laws se clean up karo — Last mein 0 aur 1 hataao
Har step mein ek hi law lagao. Jaldi mat karo — galti hogi!

Ek Aur Example: De Morgan's Wala

Simplify karo:

(A + B)' + AB = ?
Step 1: (A + B)' + AB

Hmm, ye XNOR jaisa lag raha hai! Verify karte hain truth table se:

Code Mein Boolean Algebra

if-conditions ko simple banao

Code Example 1

Ye code hai:

if ((x && y) || (x && !y)) {
    console.log("Yes!");
}

Boolean form mein likho:

Expression: XY + XY'
Step 1: X(Y + Y')    [Distributive]
Step 2: X · 1 = X    [Complement + Identity]

Simplified code:

if (x) {
    console.log("Yes!");
}
Kitna clean ho gaya! Y ka koi role hi nahi tha expression mein.

Code Example 2 — De Morgan's!

Ye code hai:

if (!(isLoggedIn && hasPermission)) {
    showError("Access denied");
}

De Morgan's Theorem 2: (A · B)' = A' + B'

Simplified (more readable):

if (!isLoggedIn || !hasPermission) {
    showError("Access denied");
}
Dono same kaam karte hain, lekin doosra wala padhne mein zyada clear hai:
"Agar logged in NAHI hai YA permission NAHI hai — toh error dikhao"

Code Example 3 — Complex Condition

Flowchart mein ye condition hai:

if ((a && b) || (a && c) || (a && !b && c)) {
    processData();
}
Expression: AB + AC + AB'C
Step 1: A(B + C + B'C)    [A common hai — Distributive]
Step 2: A(B + C)    [C + B'C = C by absorption, aur B stays]
if (a && (b || c)) {
    processData();
}
3 conditions se 2 conditions! Flowchart bhi simple ho jayega.

Practice: Truth Table Se Expression

Is truth table ka simplified expression likho:

ABF
000

Step 1: SOP (Sum of Products) likho — jahan F = 1:

F = A'B + AB' + AB

Step 2: Simplify karo:

F = A'B + A(B' + B) = A'B + A = A + B
F = A + B — ye toh OR gate hai! Truth table se pehchaan liya hota toh aur jaldi hota.

Challenge Problem!

Ye thoda mushkil hai — but try karo!
F = (A + B)(A + B')(A' + B)
Hint 1: Pehle do terms ko multiply karo
Step 1: (A + B)(A + B') = A + BB' = A + 0 = A    [Distributive (special form), Complement, Identity]
Step 2: A · (A' + B)    [Remaining term]
Step 3: AA' + AB = 0 + AB = AB    [Distributive, Complement, Identity]
F = AB
3 terms with 6 variables simplified to just 2 variables and 1 AND gate!
